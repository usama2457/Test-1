From Physics to the Modern Web

How Tim Berners-Lee's research tool became part of everyday life

The Original Purpose

In 1989, Tim Berners-Lee was working at CERN, the European physics research lab in Switzerland. Physicists there worked on different computers and kept information in different formats, so sharing research was difficult. Berners-Lee proposed a system that used hypertext to link documents together so scientists could access and share information from anywhere. By 1990 he had built the first web browser, the first web server, and the first website.

The Web Today

Today, the web is used by billions of people for things far beyond research. People use it for shopping, banking, social media, streaming video and music, online learning, and working from home. Businesses rely on web apps to run their operations, and many services that used to need special software now run in a browser.

Similarities

The core idea has not changed. The web still uses links to connect information, and it still lets people on different devices access the same content. Sharing knowledge is still one of its main uses, from academic journals to sites like Wikipedia.

Differences

The original web was made for a small group of scientists sharing mostly text documents. The modern web serves the general public and is interactive, visual, and commercial. Pages now include video, animation, and personalized content. It has also brought new problems that were not part of the original plan, such as privacy concerns, misinformation, and a few large companies controlling much of the content.
